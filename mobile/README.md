# SHAYA Flutter app

This folder is the mobile companion prototype for SHAYA COOPAI.

## Run

Install Flutter, then from this directory:

```bash
flutter pub get
flutter run
```

The app uses Material 3 and Google Fonts, with the same warm-paper / charcoal / acid-lime visual language as the React web prototype.

The current build is a frontend prototype. Government scheme data, authentication, document handling and grievance submission should be connected only through approved production APIs.
